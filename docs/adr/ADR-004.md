# ADR-004: Vite SPA instead of SSR

## Status

Accepted

## Context

Fieldspan is a multi-tenant field service platform. Architectural boundaries must stay testable as domains grow.

## Decision

Operator UI is authenticated and API-driven; SSR adds little value.

## Consequences

- Clear ownership for contributors
- Easier unit testing without the full HTTP stack
- Requires documentation updates when contracts change
