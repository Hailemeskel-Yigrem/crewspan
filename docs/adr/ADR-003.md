# ADR-003: Celery for durable background work

## Status

Accepted

## Context

Crewspan is a multi-tenant field service platform. Architectural boundaries must stay testable as domains grow.

## Decision

Notifications, webhooks, and digests run out-of-band.

## Consequences

- Clear ownership for contributors
- Easier unit testing without the full HTTP stack
- Requires documentation updates when contracts change
